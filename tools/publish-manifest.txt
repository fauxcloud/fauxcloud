# Format: one rule per line, `<class> <glob>`; `#` starts a comment line; blank lines are ignored.
#   ship <glob>      published, scanned by every rule
#   private <glob>   never published, never scanned
#   review <glob>    scanned, but refuses the export until the file is reclassified
#   binary <glob>    a binary file allowed here (images still pass the metadata check); not a class of its own
# Globs are anchored at the repository root, gitignore style: `**` spans folders, `*` and `?` stay inside one
# folder, a trailing `/` means the folder and everything under it. For ship / private / review the FIRST matching
# line wins; a tracked file that matches no line is unclassified and refuses the export.
# Lines between `# BEGIN dev-only` and `# END dev-only` are left out of the published copy of this file.
