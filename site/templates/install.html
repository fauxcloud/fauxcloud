Install fauxcloud

Write fauxcloud to your ESP32 board from this page, over USB. It takes about a minute, and there is nothing to install on your computer besides, sometimes, a USB driver.

This installer needs Chrome or Edge on a computer. It talks to the board through Web Serial, which phones, tablets, Safari and Firefox do not have. Elsewhere, flash it by hand with esptool.

This browser cannot write to a USB board.

Open this page in Chrome or Edge on a Windows, macOS or Linux computer, or flash it by hand with esptool.

Next: set it up

  1. Unplug the board, wait 30 seconds, plug it in again. Its LED should now blink fast, four times a second. If it does not, do this once more. No Wi-Fi?

  2. On your phone, join the Wi-Fi fauxcloud-setup-XXXX with the password fauxcloud: scan the QR code on this page, or pick the name in the phone's Wi-Fi list.

    XXXX stands for four characters that differ on every board; the Wi-Fi list shows the full name.

  3. Your phone may open the setup page by itself. If not, open http://fauxcloud.setup in its browser, with the http://.

  4. On the setup page, answer the four steps and press Apply.

  5. Your phone should go back to your home Wi-Fi by itself; if not, join it. Then open http://fauxcloud.local.

Go on with Get started

Unticked, the installer writes the four parts of fauxcloud and nothing else, so a board that already runs fauxcloud keeps its Wi-Fi, keys and learned values. It reads the board's flash layout first: if it differs from this version's, the installer stops and asks for this box.

No USB port in the browser's list?

Most boards carry a CP210x or a CH340 USB chip. Windows and macOS usually know the CP210x; the CH340 often needs its driver: CP210x (Silicon Labs), CH340 (WCH). Install it, unplug and replug the board, then press Connect again. A charge-only cable shows no port at all: use a USB data cable. More about cables and drivers
