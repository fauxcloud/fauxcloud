Install fauxcloud

Write fauxcloud to your ESP32 board from this page, over USB. It takes about a minute, and there is nothing to install on your computer besides, sometimes, a USB driver.

This installer needs Chrome or Edge on a computer. It talks to the board through Web Serial, which phones, tablets, Safari and Firefox do not have. Elsewhere, flash it by hand with esptool.

This browser cannot write to a USB board.

Open this page in Chrome or Edge on a Windows, macOS or Linux computer, or flash it by hand with esptool.

SELECT BOARD

Loading the list of boards…

Unticked, the installer writes the four parts of fauxcloud and nothing else, so a board that already runs fauxcloud keeps its Wi-Fi, keys and learned values. It reads the board's flash layout first: if it differs from this version's, the installer stops and asks for this box.

Board not in the list? Most boards carry a CP210x or a CH340 USB chip. Windows and macOS usually know the CP210x; the CH340 often needs its driver: CP210x (Silicon Labs), CH340 (WCH). Install it, unplug and replug the board, then press Connect again. A charge-only cable shows no port at all: use a USB data cable. More about cables and drivers
