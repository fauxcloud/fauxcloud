# Governance

fauxcloud is **open source and maintainer-led**.

- **The maintainer decides** the product, the roadmap and what is merged. The maintainer is listed in
  [AUTHORS](AUTHORS) and [.github/CODEOWNERS](.github/CODEOWNERS).
- **Contributions are welcome within the rules** of [CONTRIBUTING.md](CONTRIBUTING.md): console reports and bug reports
  first; code for issues the maintainer has accepted; every change reviewed and tested on a real board before it is
  merged. Quality comes before speed.
- **Authors stay authors.** A merged contribution keeps its author; contributors are listed in [AUTHORS](AUTHORS) and
  in the release notes.
- **Disagreement ends in a fork,** which the GPL guarantees. A fork is welcome; it is never a hostile act.
- **Time.** Issues and pull requests are read in batches, roughly once a week. No response time is promised.
- **If the project stops being maintained, it will be archived; forks are welcome.**

## AI assistance

fauxcloud is developed by one maintainer with AI assistance (Claude Code). Every change is reviewed, covered by tests
and verified on real hardware before release; the maintainer is responsible for all of it.

The same rule applies to contributors: AI help is fine if you understand the change and tested it on hardware, and you
say so in the pull request. Untested generated pull requests and AI-written security reports without a reproduction
are closed without discussion.

## Conduct

Everyone in the project's spaces follows the [Code of Conduct](CODE_OF_CONDUCT.md). The maintainer enforces it.

## Changes to this document

The maintainer changes this document by a pull request like any other change.
